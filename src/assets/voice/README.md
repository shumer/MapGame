# Recorded voice lines

Drop recordings here as `<lang>/<key>.m4a` (or `.mp3`), for example
`ru/praise-01.m4a`. They are picked up automatically at build time — no code
change needed — and replace the device's speech synthesis for that line.

Keys, phrasing and the intended delivery for every line are in
`docs/voice-script.md`.

Anything with no recording keeps using the synthesiser, so partial sets are
fine: record the praise and consolation lines first and the game already sounds
better.
