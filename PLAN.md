# MapGame - географическая игра для детей

Браузерная игра для изучения стран, флагов и столиц. Статика, без бэкенда, работает офлайн.

## Аудитория

Два профиля с разной механикой, выбираются на старте:

| | Малыш (5 лет, не читает) | Знаток (11 лет, читает) |
|---|---|---|
| Варианты ответа | 2 | 3-4 |
| Текст | минимум, всё дублируется голосом | полноценный |
| Озвучка вопроса | автоматически | по кнопке |
| Режимы | флаги, поиск на карте | все режимы |
| Столицы | выключены | включены |
| Дистракторы | из разных регионов, явно непохожие | соседние страны, похожие флаги |
| Раунд | 8 вопросов | 12 вопросов |
| Результат | звёзды и салют | звёзды, счёт, streak, рекорд |
| Ошибка | без реакции, просто показываем верный ответ | то же + вопрос вернётся раньше |

Профили в localStorage, у каждого свой прогресс.

## Наборы стран

Стартуем с Европы (45 стран). Дальше добавляем наборы: Азия, Африка, Северная Америка, Южная Америка, Океания, Весь мир.
Внутри набора сортировка по полю `fame` (1-3), от известных к редким.

## Языки

Русский, польский, английский. Язык интерфейса и язык контента выбираются отдельно
(можно учить польские названия при русском интерфейсе).

## Режимы игры

1. **Флаг -> страна.** Показываем флаг, выбор из вариантов. При верном ответе страна подсвечивается на карте.
2. **Страна -> флаг.** Обратный режим, те же данные.
3. **Найди на карте.** Даём название, ребёнок кликает страну на карте.
4. **Столица.** Название страны, выбор столицы из вариантов. При верном ответе автозум на страну и точка столицы.
5. **Покажи столицу.** Страна подсвечена, надо ткнуть в правильную точку из нескольких.

Режимы 2 и 5 почти бесплатны по данным, делаем после MVP.

## Ключевые решения

- **Ошибка не наказывает.** Никаких минус-баллов и красных крестов. Показываем верный ответ на карте, называем голосом, идём дальше.
- **Адаптивное повторение.** У каждой страны счётчик правильных подряд. После ошибки страна возвращается через 3 вопроса, потом через 8, потом через 20.
- **Конечная сессия.** Раунд из 8-12 вопросов с экраном результата, а не бесконечный поток.
- **Мелкие страны.** Автозум на регион для вопроса про микрогосударство, увеличенная хит-зона (~15px радиус), после первой ошибки подсветка континента.
- **Карточка после ответа.** Флаг, название на трёх языках, столица, один факт, кнопка "послушать".

## Стек

| Что | Чем |
|---|---|
| База | Vite + React + TypeScript |
| Карта | d3-geo + topojson-client + world-atlas (Natural Earth), рендер в SVG |
| Стиль карты | свой CSS: пастельные заливки, толстые скруглённые обводки, шрифт Nunito/Baloo |
| Флаги | пакет `flag-icons` локально (SVG, офлайн) |
| Анимации | framer-motion |
| Состояние | zustand |
| Озвучка | Web Speech API (`speechSynthesis`), ru-RU / pl-PL / en-US |
| Звуки | mp3 + howler |
| Офлайн | vite-plugin-pwa |
| Хостинг | GitHub Pages или Netlify |

Тайловые карты (MapLibre, Leaflet) не используем: тяжёлые, требуют сети, клик по стране делается сложнее.

**Риск озвучки:** качество системных голосов зависит от устройства, польский голос есть не везде.
Если качество не устроит, генерируем mp3 заранее и кладём в PWA-кэш.

## Формат данных

`src/data/countries.json`, одна запись на страну:

```json
{
  "iso": "PL",
  "un": "616",
  "name": { "ru": "Польша", "pl": "Polska", "en": "Poland" },
  "capital": { "ru": "Варшава", "pl": "Warszawa", "en": "Warsaw" },
  "capitalCoords": [21.0122, 52.2297],
  "region": "europe",
  "fame": 1,
  "mapMode": "polygon",
  "fact": { "ru": "...", "pl": "...", "en": "..." }
}
```

`un` это числовой код ISO 3166-1, по нему запись связывается с полигоном в TopoJSON.
`mapMode: "marker"` для микрогосударств, которых нет в геометрии карты (рисуем кружком).

Источник: REST Countries + Natural Earth. Переводы названий столиц выверяются вручную,
автоперевод здесь ошибается.
