# Путешествие по Европе

Браузерная игра для изучения стран, флагов и столиц Европы. Работает офлайн,
ставится на планшет как приложение, данных о пользователе никуда не отправляет.

## Запуск

```bash
npm install
npm run dev
```

Сборка в статику: `npm run build`, результат в `dist/`, кладётся на любой
статический хостинг.

## Данные

Единственный ручной источник это `src/data/countries.json`: названия, столицы
и факты на трёх языках. Всё остальное генерируется из него:

```bash
npm run data
```

Эта команда собирает карту (`europe.topo.json`), производные данные
(`derived.json`: рамки автозума, соседи, раскраска), копирует нужные флаги и
проверяет результат. Валидатор падает, если координата столицы вышла за границу
страны, пропал перевод, нет флага или соседние страны получили один цвет.

Отдельно: `npm run data:map`, `data:derived`, `data:flags`, `data:check`.

Иконки приложения рисуются из той же карты: `node scripts/build-icons.mjs`.

Страница для вычитки переводов: `node scripts/build-review-page.mjs out.html`.

## Как устроено

- `src/data` - данные и типы.
- `src/map` - проекция (коническая равноугольная, как на школьных картах
  Европы), загрузка топологии, зум с жестами, компонент карты.
- `src/game` - пресеты уровней, подбор вопросов и дистракторов, интервальное
  повторение, состояние раунда.
- `src/screens` - экраны: выбор игрока, меню, игра, результат.
- `src/store` - профили в localStorage.
- `scripts` - генерация данных, иконок и страницы вычитки.

## Два профиля

| | Малыш | Знаток |
|---|---|---|
| Варианты | 2 | 4 |
| Вопрос про флаг | название вслух, выбор из флагов | флаг, выбор из названий |
| Столицы | нет | да |
| Дистракторы | из далёких регионов | соседи |
| Раунд | 8 вопросов | 12 вопросов |
| Страны | 23 известные | все 45 |

Уровень задаётся при создании профиля и меняет почти всё поведение игры.
